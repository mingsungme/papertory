# 김민성 UXUI 디자이너 지원용 포트폴리오 — 10장 콘텐츠 스크립트

> 목적: 페이퍼토리(Com4nent) 프로젝트에서 PM 역할을 맡았던 경험을, UXUI 디자이너 직무에 맞춰 재구성.
> 이 문서는 최종 HTML 초안([kms_uxui_portfolio_draft.html](kms_uxui_portfolio_draft.html), 슬라이드 `s1`~`s10`)의 구조·순서·문구를 그대로 따르는 발표용 내레이션 스크립트다. 시각 디자인은 기존 피그마 슬라이드 스타일을 그대로 따라 별도로 작업.

## 2. 문제 정의 & 최초 가설 (s2)

**핵심 메시지:** "업무 우선순위·일정 관리"라는 PM 역할을, 문제를 구조화하고 팀의 첫 가설을 세우는 과정으로 재해석. **이 장의 끝에서 나오는 가설은 게이미피케이션이며, 이것이 팀의 '최초' 가설임을 분명히 한다** — 다음 장(s3~s4)에서 이 가설이 검증·피벗되는 순서가 이 스토리의 축이다.

**들어갈 내용:**
- 아이브로우: "01 문제 정의 & 가설", 제목: "읽어도 기록으로 안 이어진다"
- 리드: 빠르게 읽고 넘기는 소비 습관, 줄어드는 검색 유입과 트래픽으로 안 이어지는 SNS·유튜브 소비, 기록해도 다시 안 보는 습관 — 세 흐름 위에서 문제를 정의
- 문제 정의 포인트 6가지:
  1. 빠르게 읽고 넘기는 소비로 체류 시간이 저조
  2. 구글·네이버 유입은 줄어드는데 SNS·유튜브·AI챗봇 소비는 트래픽으로 전환되지 않음 — 유튜브 합산 구독자 약 390만 명이 원문 유입으로 거의 전환되지 않는 구조적 갭을 데이터로 확인
  3. 한경 내부 데이터(구글 루커스튜디오, 공유 불가)로 리텐션·이탈률을 직접 확인 — 한경 관계자들도 "구독 유입과 기사 조회 자체가 떨어지고 있다"는 걸 실제 고민으로 꼽음
  4. 중요한 정보를 찾아도 금방 잊고, 카카오톡 등에 저장해도 다시 확인하지 않음
  5. 어려운 경제 용어가 입문자의 이탈을 유발
  6. 젊은 독자가 자발적으로 공유하는 순환 구조가 형성되지 않음
- **최초 가설 인용(검증 전):** "경제 뉴스를 더 쉽고 재미있게 읽게 만들 방법이 없을까 — 그렇다면 게임 요소로 유입을 늘려보자"
- **채널별 유입 도넛차트(순수 CSS, `conic-gradient`):** 글로벌마켓 섹션 GA4 세션 데이터(2026.6.8~7.9) 기준 네이버 53.5% · 구글 44.2% · SNS 1.9% · AI 0.5% — bullet 3(한경 내부 데이터로 리텐션·이탈률 확인)을 뒷받침하는 실제 수치 시각화. 로그인·인증 리다이렉트(nid.naver.com 등)는 전 채널 공통 제외
- 클로징 노트: "이 첫 가설이 실제로 통하는지, 다음 장에서 실제 사람과 POC로 직접 검증합니다"

**근거:** [결과보고서_발표스크립트.md](docs/deliverables/report/결과보고서_발표스크립트.md) p.5–7, [채널별_유입경로_통합분석_1.md](docs/deliverables/analysis/채널별_유입경로_통합분석_1.md), 사용자 제공 GA4 CSV(`[닷컴] 글로벌마켓_글로벌마켓_표6.8~7.9.csv`, 저장소에는 미포함 — 도넛차트 수치의 1차 출처)

**들어갈 내용 (검증 트랙 3개 — 혼동하기 쉬운 지점이라 명확히 구분):**

- ① **한경 실무자 인터뷰 (1차):** 도메인 개선 과제였던 만큼, 저널리즘 DX/AX 논의에서 나온 현업 피드백을 검증 출발점으로 삼음
- ② **실제 FGI · 여성 5명 · 2026.07.14:** 약 1시간, PoC 기능 7종을 직접 시연 — 게임형 4종(3D하우스·3D펫·머니워크·독자참여재판)은 회의적, 실용형 3종(한경페이퍼·방송기사모아보기·내지갑번역기)은 호평. 현장 사진 있음
- ③ **지면 읽기 슬라이더 페르소나 인터뷰:** 원문·AI모드·쉽게읽기 3단계 슬라이더 기능에 대해 AI 페르소나 4인(조기원 외) 인터뷰로 반응 확인 — 2주간 별도 애자일 트랙으로 진행한 내용이라 세부는 별도 문서로 정리 예정, 여기선 결과만 간단히

## 4. 증명 및 대안 (s4)

**핵심 메시지:** 데이터가 최초 가설(게이미피케이션)을 깼을 때 팀을 재정렬시킨 의사결정 스토리. **여기서 처음으로 "기록이 루틴이 되면 재방문·공유·신규 유입이 함께 따라온다"는 새 가설이 등장한다 — 반드시 게임 가설이 깨진 것을 먼저 보여준 다음, 그 실패를 관찰하며 새 가설을 세웠다는 인과 순서로 전개할 것.**

**들어갈 내용:**
- 아이브로우: "03 증명 및 대안", 제목: "'게임 요소로 유입시키자'는 가설이 무너지다"
- 리드: 최초 가설이었던 게이미피케이션을 실제 POC와 리서치로 검증한 결과는 정면 부결 — 대신 이 과정에서 실용형 기능들이 즉시개발 판정을 받으며 전혀 다른 방향의 단서가 드러남
- **통계 "3/4":** AI 페르소나 챗봇 시뮬레이션 2차(압박 질문)에서 4명 중 3명이 게이미피케이션을 거부 — "기사를 읽어야 이긴다"는 강제 장치조차 거부. 실제 5인 FGI에서도 같은 방향(게임형 회의적)으로 수렴
- 포인트:
  - 3D 하우스(신문까지 걷기), 3D 펫, 재판 게임, 머니워크 — 전부 부결
  - 결정적 인사이트: 보상은 캐릭터 성장이 아니라 "내 자산·실력이 실제로 나아졌다는 증거"여야 했음
  - 구독권·세미나 참여처럼 실질적 혜택과 연결되어야 지속된다는 의견도 FGI에서 직접 나옴
  - 이 지점에서 "각자 와이어프레임을 그려보자"고 제안해 팀의 탐색 방향을 다시 엶
- **게임형 vs 실용형 비교 매트릭스 (반응 6항목):**
  - 한경 페이퍼(하이라이트+AI요약) → 즉시 개발
  - 핵심 요약 엔진 · 광고 제거 → 즉시 개발
  - 머니워크(산책 뉴스 줍기) → 부결
  - 3D 펫 육성 → 부결
  - 3D 하우스(신문까지 걷기) → 부결 — "무료라도 안 써"
  - 팩트체크 재판 · 퀴즈 타이쿤 → 부결
  - 노트: AI 페르소나 챗봇 시뮬레이션(서담채·손승호·강종희·조기원) 반응 — 실용형은 만장일치 즉시 개발, 게임형은 전부 부결. 실제 5인 FGI도 같은 방향으로 수렴
- **라이브 POC 3종 임베드** (이 판단에 실제로 쓰인 코드, 스크롤·클릭 가능):
  - 독자참여재판 — 게임형 · 부결. 핵심 문장을 "증거"로 자동 수집해 완독 후 법정 공방으로 이어지는 POC
  - 한경페이퍼 — 지면형 · 최고 호평. 원문·쉬운읽기 슬라이더 + 형광펜 + 종이신문 질감을 모바일 하나로 합친 POC
  - 형광펜 하이라이트 — 관련 기능 · 실용형에 가까움. 형광펜으로 그은 문장이 즉시 공유 카드·스크랩으로 이어지는 POC
- **피벗 인용(리서치 이후 다시 세운 가설):** "게임 요소 가설이 깨진 뒤 리서치를 다시 들여다보니, 독자들은 이미 신문에 줄을 긋고 SNS에 공유하며 스스로 '기록→공유→유입→기록' 순환을 만들고 있었습니다 — 그 액션아이템의 조회수가 특히 높았습니다. 그래서 가설을 다시 세웠습니다: 게임이 아니라, 기록이 루틴이 되면 재방문·공유·신규 유입이 함께 따라온다."

- **글래스모피즘 UI 데모 — 반드시 정확한 뉘앙스로 설명할 것:** 기사 위에 완전히 불투명한 버튼·툴바를 올리면 화면이 답답하게 막힌 느낌이 들어 읽기를 방해한다 → 그래서 상단바·FAB에 유리 표면 효과를 적용해, 요소는 분명히 구분되면서도 막힌 느낌은 들지 않도록 만듦. **이 효과의 핵심은 "문자 그대로 투명하게 비쳐 보이는 것"이 아니라 "모바일에서 기사를 읽는 동안 그 위에 얹힌 컨트롤이 답답하지 않게 느껴지는 것"** — 스크롤 가능한 가짜 기사 텍스트 위에 반투명 상단바(`←` `⋯`) + 형광펜 FAB를 얹은 라이브 미리보기로 시연. 실제 `--pt-glass-*` 토큰 값(그라디언트·블러 12px·5겹 그림자)을 그대로 재현 — 완전히 투명한 게 아니라, 스크롤해보면 배경을 은은하게 굴절시켜 답답하게 막지 않으면서도 요소 자체는 또렷이 구분되는 걸 확인할 수 있음
- 클로징 노트: 직접 만든 POC 실물은 앞의 '증명 및 대안'(s4) 장에서 3종을 라이브로 확인할 수 있음

## 10. 회고 & 다음 스텝 (s10)

KPI 정의·콘텐츠 역산 관련 항목은 이 슬라이드에 넣지 않음(최종 HTML에서 제외됨).**

- 아이브로우: "09 회고 & 다음 스텝", 제목: "끝나지 않은 루프"

  2. MAZE 사용자 조사에서 나온 구체적 개선 아이디어 — 온보딩 시 첫 액션 버튼을 강조 표시하는 가이드, 다람쥐 도토리 받기가 비활성 상태일 때 누르면 바로 완료 가능한 화면으로 이동시켜 안내하는 가이드
  3. 정식 프로젝트 기간 내에는 다 반영하지 못함 — 회고이자, 다음엔 더 챙기고 싶은 지점
